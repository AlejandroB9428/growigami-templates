# Free website templates by Growigami

38 free homepage templates for AI services firms, SaaS products and real estate brokerages. Each one is a complete, working homepage, built three times from the same design: an **Astro** project, a **HubSpot** CMS theme and a **WordPress** block theme.

Browse the gallery, open the live demos and read the install guides at **[growigami.com/templates](https://growigami.com/templates/)**.

## Downloads

The zips are the assets of the [v1 release](https://github.com/AlejandroB9428/growigami-templates/releases/tag/v1) (114 files, 136.7 MB in all). Each zip is named `<template>-<platform>.zip` and holds one folder with a README that has the full install steps. The easiest way to pick one is the gallery: every template page has a live demo, the sections and fields, and the download buttons.

| Platform | What you get | Needs |
|---|---|---|
| Astro | An Astro project: one component per section, design tokens in `src/styles/global.css`, no UI or CSS framework | Node 22.12 or newer |
| HubSpot | A CMS theme with one module per section and a Home and a Page template | A HubSpot account (free is enough) and the HubSpot CLI |
| WordPress | A block theme with one block per section, edited in the Site Editor | WordPress 6.6+ and PHP 7.4+ |

## Quick start

- **Astro:** unzip, then in the folder run `npm install` and `npm run dev` (http://localhost:4321). `npm run build` writes the static site to `dist/`.
- **HubSpot:** install the CLI (`npm install -g @hubspot/cli`), run `hs account auth`, then from the folder that holds the theme run `hs cms upload <template> <template>` and set it as the active theme.
- **WordPress:** Appearance > Themes > Add New Theme > Upload Theme, choose the zip, then Install Now and Activate.

Each template page on [growigami.com/templates](https://growigami.com/templates/) lists the sections, editable fields, fonts, colors and the condensed install steps.
